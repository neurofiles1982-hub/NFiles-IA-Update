## 🤝 Como Contribuir

Existem muitas formas de contribuir sem escrever código!

### 🐛 Relatar Bugs
1. [Abra uma issue](../../issues/new?template=bug_report.yml)
2. Descreva o problema claramente
3. Forneça passos para reproduzir
4. Anexe screenshots (sem dados pessoais)

### 💡 Sugerir Melhorias
1. [Abra uma issue](../../issues/new?template=feature_request.yml)
2. Descreva a ideia
3. Explique por que seria útil
4. Mencione apps similares se aplicável

### 📖 Melhorar Documentação
- Correções de erros de digitação
- Tradução para outros idiomas
- Exemplos práticos
- Vídeos tutoriais

### 💻 Contribuir com Código
- Veja [CONTRIBUTING.md](CONTRIBUTING.md)
- Forque o repositório
- Faça suas alterações
- Abra um Pull Request

### 🎨 Design e UX
- Mockups de interfaces
- Sugestões de logo
- Temas visuais
- Ícones e arte

### 📝 Escrever Conteúdo
- Tutoriais
- Blogs posts
- Casos de uso
- Reviews

## 📋 Regras da Comunidade

### ✅ Faça
- Seja respeitoso e educado
- Leia antes de perguntar
- Forneça detalhes completos
- Ajude outros quando puder
- Use bom senso

### ❌ Não Faça
- Spam ou auto-promoção excessiva
- Assédio ou discriminação
- Publicar dados pessoais
- Compartilhar cracks ou cópias piratas
- Linguagem abusiva

**Violações podem resultar em bloqueio permanente.**
