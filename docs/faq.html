Perguntas frequentes

Respostas diretas para usar o NFiles IA

Pesquise por instalação, desempenho, arquivos, privacidade, permissões, planos ou Colab.

Nenhuma pergunta corresponde à pesquisa. Fale com o suporte para receber ajuda.

O NFiles IA funciona no Windows 10?

Sim. A versão para desktop é destinada ao Windows 10 versão 1809 ou posterior e ao Windows 11, ambos em 64 bits. Recomendamos manter o Windows atualizado.

Preciso instalar Python?

Não. O instalador oficial fornece as dependências necessárias. Python é requisito somente para desenvolvedores que executam o código-fonte.

Quanto de memória e espaço preciso?

O mínimo funcional é 4 GB de RAM e 6 GB livres. Para uma experiência melhor, recomendamos 8 GB de RAM e 10 GB livres em SSD.

Preciso de uma placa de vídeo dedicada?

Não. O NFiles IA funciona em CPU e adapta o uso de recursos. Uma máquina mais forte pode acelerar tarefas, mas não é necessária para abrir e usar as funções essenciais.

O sistema funciona sem internet?

Funções locais já instaladas podem funcionar offline. Internet é necessária para download, atualizações, pesquisa web, conexão com Colab e componentes opcionais.

O que significa “modo compatível”?

Significa que o NFiles IA ajustou automaticamente memória, processador e tempo de resposta para o computador atual. As funções e proteções do produto continuam disponíveis dentro dos limites do hardware.

O NFiles IA envia meus arquivos?

Não silenciosamente. Arquivos selecionados são processados localmente por padrão. Ao usar voluntariamente Colab, pesquisa web ou suporte, somente o conteúdo necessário à ação escolhida pode ser transmitido conforme a política de privacidade.

O que é o Colab no NFiles IA?

É uma opção para conectar uma sessão temporária criada pelo próprio usuário e acelerar respostas. A conexão não é obrigatória, o token não deve ser compartilhado e a sessão pode expirar.

A IA pode executar ferramentas do sistema?

Sim, apenas por meio do catálogo interno do NFiles e conforme o nível de acesso escolhido. Caminhos, permissões, plano, risco e necessidade de confirmação são verificados.

Qual nível de acesso devo escolher?

Comece com “Perguntar antes”. “Aprovar para mim” automatiza ações autorizadas mantendo confirmação nas destrutivas. “Acesso total” deve ser usado somente quando você compreender a tarefa.

As respostas da IA podem estar erradas?

Sim. Conteúdo gerado pode conter erros ou ficar incompleto. Revise respostas importantes e denuncie conteúdo inadequado pelo recurso disponível no chat ou pelo suporte.

O NFiles substitui antivírus?

Não. As verificações de segurança são complementares. Mantenha o Microsoft Defender ou outro antivírus confiável ativo e atualizado.

O NFiles apaga arquivos automaticamente?

As telas de limpeza, organização e duplicados apresentam prévias. Alterações dependem da ação do usuário e das confirmações previstas pelo nível de acesso.

O NFiles Radio é obrigatório?

Não. Ele é gratuito, separado e opcional. No instalador, permanece desmarcado por padrão e só é baixado quando o usuário escolhe essa opção.

Como atualizo o aplicativo?

Use o canal oficial de atualizações ou a Microsoft Store quando a edição estiver disponível nela. Não instale atualizações oferecidas por páginas de terceiros.

Como obtenho suporte?

Acesse a página de suporte para usar o e-mail, telefone/WhatsApp ou abrir uma solicitação pública sem incluir dados pessoais.
