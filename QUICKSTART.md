# ⚡ Início Rápido - NFiles IA

> Da instalação ao primeiro uso em 5 minutos

---

## 📥 Passo 1: Download (1 minuto)

**Clique aqui:** [Baixar NFiles IA v8.0.4](../../releases/download/v8.0.4/NFilesIA_Setup_v8.0.4.exe)

Ou:
1. Vá para [Releases](../../releases)
2. Clique em `NFilesIA_Setup_v8.0.4.exe`
3. Clique em "Download"
4. Aguarde completar

---

## 🔧 Passo 2: Instalação (2 minutos)

1. Abra o arquivo `NFilesIA_Setup_v8.0.4.exe`
2. Se Windows SmartScreen aparecer:
   - Clique "Mais informações" → "Executar assim mesmo"
3. Clique em "Instalar"
4. Aguarde completar
5. Pronto! 🎉

---

## 🚀 Passo 3: Primeiro Uso (2 minutos)

### Abrir o App
1. NFiles IA abrirá automaticamente
2. Ou procure no Menu Iniciar

### Configuração Inicial
1. Aceite os termos (leia rápido)
2. Selecione pasta padrão (seu Documents)
3. Configure IA (local ou Colab)
4. Clique em "Começar"

### Pronto para Usar!
- 📁 Organize seus arquivos
- 🤖 Converse com a IA
- 🧹 Limpe seu disco

---

## 🎯 Seus Primeiros Passos

### 1. Explorar a Interface
```
┌─────────────────────────────┐
│  Menu  │  Chat da IA        │
├────────┤────────────────────│
│ • Arquivos                   │
│ • Limpeza                    │  Converse aqui
│ • Ferramentas                │  com a IA!
│ • Configurações              │
└─────────────────────────────┘
```

### 2. Organize Seus Arquivos
1. Clique em "Arquivos"
2. Selecione uma pasta
3. Clique em "Explorar"
4. Veja tudo organizado!

### 3. Converse com a IA
1. Abra a aba "Chat"
2. Digite sua pergunta
3. Pressione Enter
4. A IA responde!

**Exemplos de perguntas:**
- "Qual é o maior arquivo aqui?"
- "Quantos PDFs tenho?"
- "Como organizar por data?"
- "O que são esses arquivos duplicados?"

### 4. Limpe Seu Disco
1. Clique em "Limpeza"
2. Selecione uma pasta
3. Clique em "Analisar"
4. Revise sugestões
5. Clique em "Limpar" (com confirmação)

## ⚙️ Configuração Essencial

### IA Local vs Google Colab

**Local (Padrão)**
- ✅ Sem internet necessária
- ✅ Privado 100%
- ❌ Mais lento
- ✅ Melhor para começar

**Google Colab (Avançado)**
- ✅ Muito rápido
- ⚠️ Requer internet
- ⚠️ Dados vão para Google
- ✅ Melhor para grandes análises

**Como Configurar:**
1. Vá para `Menu` → `Configurações`
2. Clique em "IA"
3. Escolha uma opção
4. Clique "Salvar"

## 💡 Dicas Rápidas

### 🎮 Atalhos de Teclado
| Tecla | Ação |
|-------|------|
| `Ctrl+O` | Abrir arquivo |
| `Ctrl+L` | Limpar histórico |
| `Ctrl+,` | Configurações |
| `Ctrl+/` | Ajuda |
| `Ctrl+Q` | Sair |

### 💾 Boas Práticas
- Sempre revise sugestões antes de deletar
- Backup importante antes de limpeza
- Use "Desfazer" se algo der errado (Ctrl+Z)
- Consulte a IA quando tiver dúvida

### 🔒 Privacidade
- Seus arquivos nunca saem do seu PC
- A IA local processa tudo localmente
- Dados pessoais são SEUS
- Sem rastreamento
