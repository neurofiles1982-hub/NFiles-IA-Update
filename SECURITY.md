# Segurança

Não publique vulnerabilidades exploráveis, tokens, licenças ou dados pessoais em uma Issue pública.

Envie relatos sensíveis para `neurofilesaipro@hotmail.com` com a versão afetada, impacto observado e passos mínimos para reprodução. Evite anexar documentos reais; use exemplos sem dados pessoais.

Problemas funcionais sem conteúdo sensível podem ser relatados pelos formulários públicos de Issues.
